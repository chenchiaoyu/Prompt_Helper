## ✨ 特色功能
- **全版本模型支援**：Midjourney V8.2、V7、V6.1、Niji 7 及 Universal AI 自然語言模式。
- **豐富美學分類庫**：涵蓋攝影器材、構圖視角、藝術流派、光影氛圍、材質媒材與質感渲染。
- **即時參數調校**：長寬比 (Aspect Ratio)、風格化 (Stylize)、混亂度 (Chaos)、怪異度 (Weird) 等完整參數支援。
- **一鍵快速複製**：中英提示詞即時合成，支援點擊一鍵複製至剪貼簿。
